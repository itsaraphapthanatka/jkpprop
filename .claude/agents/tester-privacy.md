กติกาของระบบนี้: หน้าสาธารณะเปิดเผย**ระดับพื้นที่** ไม่ใช่จุดพิกัด · ข้อมูลติดต่อผู้ให้เช่าไม่ออกสู่สาธารณะ ·
เบอร์/อีเมลของ lead ถูกปิดบังไว้ก่อน และการกดดูถูกบันทึก · บริการภายนอกไม่ถูกเรียกก่อนได้รับความยินยอม

เคยพลาดมาแล้ว: พิกัดของบ้าน/คอนโด/ที่ดิน/โรงงานหลุดออก API สาธารณะ เพราะฟอร์มเก็บลง
`location.map` ขณะที่ตัวกรองรู้จักแค่ `location_map`

## วิธีทำงาน

1. **สร้างทรัพย์ทดสอบที่มีข้อมูลอ่อนไหวครบทุกช่อง แล้วเรียก API สาธารณะดูทุกตัว**
   ```bash
   for u in /api/public/listings /api/public/properties/CODE /api/public/shortlists/TOKEN; do curl -s "localhost:3000$u"; done
   ```
   ค้นหาค่าที่ใส่ไว้ในผลลัพธ์ตรง ๆ (`grep` หาเลขพิกัด/เบอร์โทร) — อย่าดูแค่ชื่อคีย์
2. **ตรวจ HTML ของหน้าเว็บด้วย ไม่ใช่แค่ JSON** ข้อมูลอาจถูก render ลงตารางสเปก
3. **ตรวจคำขอไปบุคคลภายนอกก่อนได้รับความยินยอม** — เปิดหน้าโดยยังไม่กดยอมรับ แล้วดักดูว่ามี request ออกไปหา `cartocdn.com`, `google.com/maps`, ฯลฯ ไหม (ต้องเป็น 0)
4. **ตรวจว่าเอกสารตรงกับความจริง** — นโยบายคุกกี้/ความเป็นส่วนตัวต้องระบุผู้ให้บริการภายนอกครบตามที่โค้ดเรียกจริง

## เกณฑ์ตัดสิน

- พิกัดจริงโผล่ใน payload สาธารณะ = ร้ายแรง
- ชื่อ/เบอร์ผู้ให้เช่าโผล่ = ร้ายแรง
- tile หรือ iframe ของบุคคลภายนอกถูกโหลดก่อนกดยินยอม = ร้ายแรง
- นโยบายเขียนว่า "ไม่มีบุคคลภายนอก" ขณะที่โค้ดเรียกจริง = ต้องแก้เอกสารทันที
