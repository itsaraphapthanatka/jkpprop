โครงสร้างของโปรเจกต์นี้: `dictionaries.ts` เก็บข้อความ UI ทั้งสามภาษา · `enums.ts` ใช้
**ค่าภาษาไทยเป็นคีย์** แล้วแปลตอน render ด้วย `enumLabel` · ชื่อจังหวัด/อำเภออยู่ใน `places.ts` ·
ชื่อทรัพย์และคำบรรยายเป็นข้อมูล เก็บคำแปลไว้ในคอลัมน์ `i18n` ของแต่ละ record

มีเทสต์ยามอยู่แล้วที่ `web/tests/unit/publicCopy.test.ts` — มันจะแดงถ้ามีข้อความไทยเขียนตรง ๆ
ในคอมโพเนนต์สาธารณะ **อย่าปิดหรือใส่ข้อยกเว้นให้มันเพื่อให้ผ่าน**

## วิธีทำงาน

1. `cd web && npm test` ดูว่า publicCopy กับ i18n ผ่านไหมก่อน
2. **เปิดหน้าเดียวกันทั้งสามภาษาแล้วเทียบข้อความจริง** ไม่ใช่แค่เช็คว่าคีย์มีครบ:
   ```bash
   for l in th en zh; do curl -s "localhost:3000/$l/listing" | grep -o "ตร\.ม\.\|ให้เช่า\|โกดัง" | sort -u | tr '\n' ' '; echo " ← $l"; done
   ```
   ถ้าเห็นคำไทยในผลของ `en`/`zh` แปลว่ามีอะไรหลุด
3. **ตรวจค่าที่มาจากฐานข้อมูล** — ประเภททรัพย์ สถานะ พื้นที่สีผังเมือง ชื่อจังหวัด ต้องผ่าน `enumLabel`/`provinceLabel`
4. **ตรวจ metadata** — `<title>`, description, canonical, hreflang ต้องเป็นภาษาของหน้านั้น
5. **ตรวจรูปแบบตัวเลข/วันที่** — วันที่ต้องใช้ locale ที่ถูก (`th-TH` / `en-GB` / `zh-CN`)

## เกณฑ์ตัดสิน

- คำไทยโผล่ในหน้า /en หรือ /zh = พัง (ยกเว้นชื่อเฉพาะ เช่น ชื่อบริษัท)
- ค่า enum แสดงเป็นค่าดิบภาษาไทย = พัง
- คีย์มีครบสามภาษาแต่แปลผิดความหมาย = รายงานไว้ แม้เทสต์จะเขียว
- ข้อความที่แปลแล้วยาวจนล้นกรอบบนจอ 412px = รายงานพร้อมภาพ
