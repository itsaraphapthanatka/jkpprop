JKP Property · คู่มือทีมงาน

นำเข้าข้อมูลทรัพย์ทีละหลายรายการ

กรอกข้อมูลทรัพย์ลงไฟล์ Excel แล้วให้ระบบสร้างให้ทีเดียวทั้งหมด แทนการเพิ่มทีละรายการในหน้า Properties

อ่านก่อน

ตอนนี้ทีมกรอกไฟล์เองได้ แต่ยังกดนำเข้าเองไม่ได้ — ยังไม่มีปุ่มอัปโหลดในหน้า admin ขั้นตอนสุดท้ายต้องส่งไฟล์ให้คนที่เข้าเซิร์ฟเวอร์ได้เป็นคนรัน

คู่มือนี้ครอบคลุมส่วนที่คุณทำเองได้ทั้งหมด คือกรอกไฟล์ให้ถูกตั้งแต่รอบแรก ซึ่งเป็นส่วนที่ใช้เวลามากที่สุดและผิดพลาดง่ายที่สุด

ขั้นตอนทั้งหมด

ขอไฟล์เปล่าตามประเภททรัพย์

แต่ละประเภทมีคอลัมน์ไม่เหมือนกัน โกดังมี 53 คอลัมน์ โรงงานมี 20 ขอไฟล์ให้ตรงประเภทที่จะกรอก จะได้มาสองไฟล์ต่อประเภท

ไฟล์ใช้ทำอะไร
warehouse.csv ไฟล์ที่กรอกจริง — บรรทัดแรกคือชื่อคอลัมน์ ห้ามแก้หรือสลับ
warehouse-อธิบาย.csv เปิดคู่กันไว้ดู — บอกว่าแต่ละคอลัมน์คืออะไร กรอกแบบไหน และมีค่าอะไรให้เลือกบ้าง

กรอกใน Excel — หนึ่งแถวคือหนึ่งทรัพย์

เปิดด้วย Excel หรือ Google Sheets ได้เลย ภาษาไทยไม่เพี้ยน ลบแถวตัวอย่างทิ้งก่อน แล้วเริ่มกรอกจากแถวถัดไป

ช่องไหนไม่มีข้อมูลให้เว้นว่าง ไม่ต้องใส่ - หรือ ไม่มี — ระบบจะเก็บคำนั้นเป็นข้อมูลจริงแล้วเอาไปแสดงบนเว็บ

ส่งไฟล์ให้ทีมเทคนิคตรวจ

ระบบจะไล่ตรวจทุกแถวก่อนเขียนข้อมูลจริง ถ้ามีจุดผิดจะบอกกลับมาเป็นเลขบรรทัดกับชื่อคอลัมน์ เช่น บรรทัด 12 · usable_area · "ประมาณ 800" ไม่ใช่ตัวเลข

ปลอดภัย

ถ้ามีแถวไหนผิด ระบบจะไม่เขียนสักแถว พิมพ์ผิดบรรทัดที่ 60 จะไม่เหลือทรัพย์ค้างครึ่ง ๆ กลาง ๆ 59 รายการให้ตามลบ แก้ไฟล์แล้วส่งใหม่ได้เลย

ตรวจผลในหน้า Properties

ทรัพย์ที่นำเข้าจะขึ้นในหน้า Properties พร้อมรหัสที่ระบบออกให้ แก้ไขต่อในหน้า admin ได้ตามปกติ

สี่คอลัมน์แรก มีเหมือนกันทุกประเภท

ใส่รหัสเดิมเมื่อต้องการแก้ไขทรัพย์ที่มีอยู่แล้ว
title จำเป็น ชื่อทรัพย์ที่จะแสดงบนเว็บ เช่น โกดังพร้อมสำนักงาน 2,700 ตร.ม. บางนา
status draft ยังไม่เผยแพร่ · active ใช้งาน · hidden ซ่อน
เว้นว่าง = draft

จังหวัดมีผลกับรหัสทรัพย์

ระบบออกรหัสจากช่อง province กรุงเทพฯ ได้ JKP0001 จังหวัดอื่นได้ JKP-CBI0001 โดย CBI คือรหัสชลบุรี

แก้ทีหลังไม่ได้

รหัสทรัพย์ออกแล้วเปลี่ยนไม่ได้ตลอดไป ลืมกรอกจังหวัดจะได้รหัสแบบกรุงเทพฯ ติดไปกับทรัพย์นั้นถาวร ลบทรัพย์ทิ้งแล้วเลขที่ใช้ไปก็ไม่ย้อนกลับมา — ตรวจช่องจังหวัดก่อนส่งไฟล์ทุกครั้ง
